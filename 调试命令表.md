# 调试命令表

本文整理 `ROS2 Smart Follower` 当前主线（beta-0.3.x）常用调试命令。

当前主线默认：
- launch 入口：`smart_follower.launch.py`
- 相机输入：`/camera/color/image_raw` + `/camera/depth/image_raw`
- 内参服务：`/camera/get_camera_info`
- 关键输出：`/robot1/person_pose`、`/robot1/cmd_vel_follow`、`/robot1/cmd_vel_avoid`、`/cmd_vel`
- 默认命名空间：`robot1`

---

## 2. 启动命令

### 2.1 启动完整链路
```bash
ros2 launch smart_follower_bringup smart_follower.launch.py
```

### 2.2 不启动底盘，只起本项目
```bash
ros2 launch smart_follower_bringup smart_follower.launch.py \
  robot_ns:=robot1 \
  bringup_robot:=false
```

### 2.3 不启动相机，自己注入测试数据
```bash
ros2 launch smart_follower_bringup smart_follower.launch.py \
  robot_ns:=robot1 \
  bringup_robot:=false \
  bringup_camera:=false
```

### 2.4 不启动底盘也不启动相机
```bash
ros2 launch smart_follower_bringup smart_follower.launch.py \
  robot_ns:=robot1 \
  bringup_robot:=false \
  bringup_camera:=false
```

### 2.5 手工单起 perception
```bash
ros2 run smart_follower_perception perception_node --ros-args \
  --params-file src/smart_follower_bringup/config/perception_params.yaml \
  -r __ns:=/robot1
```

### 2.6 手工单起 follower controller
```bash
ros2 run smart_follower_control follower_controller_node --ros-args \
  --params-file src/smart_follower_control/config/control_params.yaml \
  -r __ns:=/robot1
```

### 2.7 手工单起 arbiter
```bash
ros2 run smart_follower_control arbiter_node --ros-args \
  --params-file src/smart_follower_control/config/control_params.yaml \
  -r __ns:=/robot1
```

## 3. 常用状态查看

### 3.1 查看节点列表
```bash

```

### 3.2 查看话题列表
```bash
ros2 topic list | sort
```

### 3.3 查看服务列表
```bash

```

### 3.4 查看参数列表
```bash
ros2 param list /robot1/perception_node

```

### 3.5 查看 lifecycle 状态
```bash
ros2 lifecycle get /robot1/perception_node

ros2 lifecycle get /robot1/obstacle_avoidance_node
ros2 lifecycle get /robot1/arbiter_node

```

### 3.6 实时状态面板（推荐）
```bash
cd ~/ros2_smart_follower
source /opt/ros/humble/setup.bash
source /home/wheeltec/wheeltec_ros2/install/setup.bash
source install/setup.bash
python3 tools/live_dashboard.py --robot-ns robot1
```

可选：降低刷新频率，减少终端刷新压力
```bash
python3 tools/live_dashboard.py --robot-ns robot1 --refresh-hz 2
```

面板布局固定为：
- 上排 3 块：System / Camera / Perception
- 中排 3 块：Locked Target / Follower / Obstacle+Arbiter
- 下排 1 块：Warnings

退出方式：`Ctrl+C`

### 3.7 Textual 集成仪表盘（推荐正式版）
先安装依赖：
```bash
python3 -m pip install textual
```

启动：
```bash
cd ~/ros2_smart_follower
source /opt/ros/humble/setup.bash
source /home/wheeltec/wheeltec_ros2/install/setup.bash
source install/setup.bash
python3 tools/live_dashboard_textual.py --robot-ns robot1
```

可选：调整显示缩放（注意：这是终端内容缩放，不是系统字体本身）
```bash
python3 tools/live_dashboard_textual.py --robot-ns robot1 --ui-scale large
python3 tools/live_dashboard_textual.py --robot-ns robot1 --ui-scale compact
```

默认集成快捷键：
- `L`：自动锁定（沿用当前 auto lock 逻辑）
- `↑` / `↓`：切换目标表选中项
- `Enter`：锁定当前选中的 target_id
- `U`：解锁
- `R`：重置
- `Q`：急停
- `-` / `=`：缩小 / 放大显示
- `X`：退出仪表盘

说明：
- Textual 版是正式版，支持组件化刷新 + FollowCommand 控制
- 若当前环境没有 `textual`，可回退到轻量版：
```bash
python3 tools/live_dashboard.py --robot-ns robot1
```

## 4. 感知链路调试

### 4.1 看 color / depth 输入频率
```bash
ros2 topic hz /camera/color/image_raw
ros2 topic hz /camera/depth/image_raw
```

### 4.2 看 `/person_pose` 输出频率
```bash
ros2 topic hz /robot1/person_pose
```

### 4.3 看 `/person_pose` 单次内容
```bash
ros2 topic echo /robot1/person_pose --once
```

### 4.4 持续看 `/person_pose`
```bash
ros2 topic echo /robot1/person_pose
```

### 4.5 查看相机内参服务是否可用
```bash
ros2 service list | grep get_camera_info
ros2 service type /camera/get_camera_info
```

### 4.6 直接调用相机内参服务
```bash
ros2 service call /camera/get_camera_info astra_camera_msgs/srv/GetCameraInfo "{}"
```

### 4.7 看 perception 节点参数
```bash
ros2 param get /robot1/perception_node color_topic
ros2 param get /robot1/perception_node depth_topic
ros2 param get /robot1/perception_node process_every_n_frames
ros2 param get /robot1/perception_node yolo.ort.intra_op_num_threads
ros2 param get /robot1/perception_node camera.info_service
ros2 param get /robot1/perception_node depth_compare.sample_window_px
```

### 4.8 动态调 perception 参数
```bash
ros2 param set /robot1/perception_node process_every_n_frames 2
ros2 param set /robot1/perception_node yolo.ort.intra_op_num_threads 1
ros2 param set /robot1/perception_node depth_compare.sample_window_px 7
ros2 param set /robot1/perception_node depth_compare.min_valid_samples 5
```

### 4.9 看 diagnostics
```bash
ros2 topic echo /diagnostics
```

### 4.10 只看 rosout 里 perception 相关日志
```bash
ros2 topic echo /rosout | grep perception_node
```

## 7. 锁定 / 解锁 / 急停

### 7.1 键盘节点默认按键
- `l`：锁定
- `u`：解锁
- `r`：重置
- `q`：急停

### 7.2 手工发 FollowCommand（示例）
先看消息结构：
```bash
ros2 interface show smart_follower_msgs/msg/FollowCommand
```

再按实际字段发布，例如：
```bash
ros2 topic pub --once /robot1/follow_command smart_follower_msgs/msg/FollowCommand "{}"
```

> 说明：这个命令要以当前消息定义为准，先 `interface show` 再填字段，避免字段名写错。

## 12. 最常用的一组最小排障命令

如果你现在只想快速判断“链路活没活”，先跑这几个：

```bash
ros2 node list | sort
ros2 topic hz /camera/color/image_raw
ros2 topic hz /camera/depth/image_raw
ros2 service list | grep get_camera_info
ros2 topic hz /robot1/person_pose
ros2 topic echo /robot1/person_pose --once
ros2 topic hz /robot1/cmd_vel_follow
ros2 topic echo /cmd_vel --once
```

如果你只想快速判断“控制为什么不跟”：

```bash
ros2 topic echo /robot1/person_pose --once
ros2 topic echo /robot1/cmd_vel_follow --once
ros2 topic echo /cmd_vel --once
ros2 param get /robot1/follower_controller_node target_distance
ros2 param get /robot1/follower_controller_node theta_deadzone
```
